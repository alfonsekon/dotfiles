# Browser Keyboard Shortcuts
These are only the *vanilla* vivaldi shortcuts. Apart from this, I have [`vimium`](https://github.com/philc/vimium/blob/master/README.md) installed... btw\
\
**link to shortcuts** - [`vivaldi:settings`](vivaldi:settings)

## Navigation & Page Actions

- **History Back**: `Alt + ←`
- **History Forward**: `Alt + →`
- **Reload Page**: `Ctrl + R`, `F5`
- **Force Page Reload**: `Ctrl + Shift + R`, `Ctrl + F5`
- **Stop Loading**: `Esc`
- **Homepage**: `Alt + Home`
- **Find in Page**: `Ctrl + F`
- **Find Next**: `F3`, `Ctrl + G`
- **Find Previous**: `Shift + F3`, `Ctrl + Shift + G`
- **Focus Address Field**: `F8`, `Ctrl + L`
- **Focus Search Field**: `Ctrl + K`
- **Focus Page**: `F9`
- **Copy Selected Text to Note**: `Ctrl + Shift + C`
- **Spatial Navigation**: `Shift + Arrow Keys` (Up, Down, Left, Right)
- **Open File**: `Ctrl + O`
- **Save Page As**: `Ctrl + S`

## Tabs Management

- **New Tab**: `Ctrl + T`
- **Close Tab**: `Ctrl + W`, `Ctrl + F4`
- **Reopen Closed Tab**: `Ctrl + Shift + T`
- **Duplicate Tab**: `Ctrl + Alt + Y`
- **Pin / Unpin Tab**: `Alt + P`
- **Tab Cycler Forward**: `Ctrl + Tab`
- **Tab Cycler Back**: `Ctrl + Shift + Tab`
- **Next Tab (by Order)**: `Ctrl + PageDown`, `Ctrl + Alt + N`
- **Previous Tab (by Order)**: `Ctrl + PageUp`, `Ctrl + Alt + P`
- **Move Active Tab Forward**: `Ctrl + Shift + PageDown`, `Ctrl + Alt + Shift + N`
- **Move Active Tab Backward**: `Ctrl + Shift + PageUp`, `Ctrl + Alt + Shift + P`
- **Switch to Tab 1-8**: `Ctrl + [1-8]`, `Ctrl + Numpad[1-8]`
- **Switch to Last Tab**: `Ctrl + 9`, `Ctrl + Numpad9`
- **Select Next Tab**: `Ctrl + Alt + O`
- **Select Previous Tab**: `Ctrl + Alt + U`
- **Tile Vertically**: `Ctrl + F9`, `Ctrl + Alt + I`
- **Tile Horizontally**: `Ctrl + F8`
- **Tile to Grid**: `Ctrl + F7`
- **Untile All Tabs in Set**: `Ctrl + F6`, `Ctrl + Alt + J`
- **Mute / Unmute Tab**: `Ctrl + M`

## Window & UI Management

- **New Window**: `Ctrl + N`
- **New Private Window**: `Ctrl + Shift + N`
- **Close Window**: `Ctrl + Shift + W`
- **Quick Commands**: `Ctrl + E`, `F2`, `Alt + T`
- **Settings**: `Ctrl + F12`, `Ctrl + ,`
- **Task Manager**: `Shift + Esc`
- **Exit**: `Ctrl + Q`
- **Keyboard Cheat Sheet**: `Ctrl + F1`
- **Focus Next Pane**: `F6`
- **Focus Previous Pane**: `Shift + F6`
- **Toggle UI**: `Ctrl + F11`
- **Fullscreen Mode**: `F11`
- **Customize Toolbar**: `Ctrl + Alt + K`
- **Toggle Force Dark Theme on all websites**: `Ctrl + Alt + \`

## Panels & Bars

- **Panel (Toggle)**: `F4`, `Ctrl + Alt + ]`
- **Focus Panel**: `F7`
- **Open Next Panel**: `Alt + F7`
- **Open Previous Panel**: `Alt + Shift + F7`
- **Address Bar**: `Ctrl + Alt + L`
- **Bookmarks Bar**: `Ctrl + Shift + B`
- **Status Bar**: `Ctrl + Shift + S`
- **Tab Bar**: `Ctrl + Alt + [`
- **Downloads Panel**: `Ctrl + Shift + D`, `Ctrl + J`
- **History Panel**: `Ctrl + Shift + H`
- **Notes Panel**: `Ctrl + Shift + O`
- **Mail Panel**: `Ctrl + Shift + M`

## Zoom

- **Page Zoom In**: `Ctrl + +`, `Ctrl + =`
- **Page Zoom Out**: `Ctrl + -`
- **Page Zoom Reset**: `Ctrl + 0`, `Ctrl + Numpad0`, `Ctrl + *`

## Workspaces

- **Next Workspace**: `Alt + Shift + N`, `Alt + E`, `Ctrl + Alt + →`
- **Previous Workspace**: `Alt + Shift + P`, `Alt + Q`, `Ctrl + Alt + ←`
- **Create New Workspace**: `Alt + Shift + C`
- **Switch to Window**: `Ctrl + Shift + 1`
- **Switch to Workspace 1 (Cube)**: `Ctrl + Shift + 2`
- **Switch to Workspace 2 (home)**: `Ctrl + Shift + 3`
- **Switch to Workspace 3 (school)**: `Ctrl + Shift + 4`
- **Switch to Workspace 4 (Yob)**: `Ctrl + Shift + 5`
- **Switch to Workspace 5-8**: `Ctrl + Shift + [6-9]`

## Tools & Miscellaneous

- **Create Bookmark**: `Ctrl + D`
- **History (Manager)**: `Ctrl + H`
- **Bookmarks (Manager)**: `Ctrl + B`
- **Extensions**: `Ctrl + Shift + E`, `Ctrl + .`
- **Print**: `Ctrl + P`
- **View Page Source**: `Ctrl + U`
- **Developer Tools (Toggle)**: `Ctrl + Shift + I`, `F12`
- **Developer Tools Console**: `Ctrl + Shift + J`
- **Delete Browsing Data**: `Ctrl + Shift + Del`
- **Paste and Go**: `Ctrl + Shift + V`
- **Copy URL**: `Ctrl + Alt + '`
